# Documentação do Carina

Bem-vindo. Esta pasta reúne tudo o que você precisa para **instalar, usar
e tirar proveito** do Carina — do primeiro clique ao planejamento de uma
noite inteira de observação.

> **Versão documentada: 0.13.2** — produto em desenvolvimento. Recursos e
> telas podem mudar entre versões; quando isso acontecer, esta pasta é
> atualizada junto.

## Por onde começar

Se você **nunca abriu o programa**, siga esta ordem:

1. **[Instalação](INSTALACAO.md)** — colocar o Carina para rodar
2. **[Primeiros passos](PRIMEIROS_PASSOS.md)** — um passeio guiado de
   ponta a ponta, terminando com um plano de observação impresso
3. **[Interface](INTERFACE.md)** — a referência de cada menu e botão,
   para consultar quando precisar

## Convenções desta documentação

- **`Ctrl+F`** — teclas são escritas assim; no macOS, troque `Ctrl` por `Cmd`.
- *Menu → Submenu → Item* — caminhos de menu aparecem em itálico com setas.
- Os exemplos usam **Rio de Janeiro** como local e datas de **2026**,
  que é o padrão de fábrica; os seus resultados dependem da sua cidade,
  da data e da sua classe de Bortle.
